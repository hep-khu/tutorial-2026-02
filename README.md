# 2026년 2학기 학부생 연구연수 프로그램
## 개요
- 경희대 물리학과 학부생이 한 학기에 두 개 연구실의 연구에 참여함
- 입자실험 연구실에서는 이번 학기 전반기에 두 명의 학생(석예나, 이동규)이 연구연수 프로그램에 참여.
- 이번 학기는 고정환 교수가 직접 진행함.
- pyROOT를 이용해 CMS Open Data 기초 데이터 분석 등을 진행할 것.
